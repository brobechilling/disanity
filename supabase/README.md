# Supabase Backend

This folder is reserved for Supabase project assets.

```text
supabase/
  migrations/  SQL schema migrations
  functions/   Supabase Edge Functions
  seed.sql     Local/dev seed data
```

Recommended domain tables for DiSanity later:

- `profiles`
- `artisans`
- `workshops`
- `workshop_sessions`
- `bookings`
- `booking_items`
- `reviews`
- `media_assets`

Add row-level security policies before using real customer or artisan data.
